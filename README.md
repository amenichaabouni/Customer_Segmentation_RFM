**InsightStream – Real-time Customer Segmentation Web App** <br>
• Analyzed customer data in real-time for personalized marketing strategies.<br>
• Segmented customers dynamically based on purchasing behavior.<br>
• Visualized insights through an interactive and user-friendly interface.<br>
• Utilized MLOps to select the optimal model between KMeans and Agglomerative clustering.<br>
